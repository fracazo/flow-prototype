# Flow prototype

A clickable mobile flow prototype for coding agents. The map shows every screen. Live walks one path inside an iPhone.

```bash
npx skills add fracazo/flow-prototype
```

[skills.sh/fracazo/flow-prototype](https://skills.sh/fracazo/flow-prototype)

The installed skill includes a `template/` folder. Copy that into an empty project, run `npm install`, then replace `flows.md` with the product.
